Refatoração para Classe - POO em PHP

Projeto desenvolvido em PHP utilizando Programação Orientada a Objetos (POO) para realizar a classificação acadêmica de um aluno.

O sistema foi refatorado para utilizar uma classe Aluno, aplicando encapsulamento, tipagem forte e métodos para cálculo da situação final.

Funcionalidades
Cadastro do nome e nota do aluno;
Cálculo da situação acadêmica;
Uso de classe e objetos;
Validação dos dados informados.
Classificação
Nota maior ou igual a 7: Aprovado
Nota entre 5 e 6,9: Recuperação
Nota menor que 5: Reprovado
Tecnologias utilizadas
PHP 8.x
HTML
CSS
Conceitos aplicados
Programação Orientada a Objetos;
Classes e objetos;
Encapsulamento;
Tipagem forte;
Métodos e construtor.
