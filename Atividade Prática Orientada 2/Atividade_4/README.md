# Alissa Garcia Moreira

## Classe Abstrata e Trait

Projeto desenvolvido em PHP utilizando Programação Orientada a Objetos.

O sistema utiliza uma classe abstrata `Pessoa`, as classes `Aluno` e `Professor` com herança e a trait `Identificacao` para reutilização de código.

### Funcionalidades

* Criar alunos e professores;
* Utilizar herança entre classes;
* Reutilizar métodos com traits;
* Exibir informações das pessoas.

### Tecnologias utilizadas

* PHP 8.x
* HTML
* CSS

### Conceitos aplicados

* Programação Orientada a Objetos;
* Classes abstratas;
* Herança;
* Traits;
* Encapsulamento;
* Tipagem forte.

### Como executar

```bash
php -S localhost:8000
```

Depois, acesse:

```text
http://localhost:8000
```
