Gerenciador de Turma

Projeto desenvolvido em PHP utilizando Programação Orientada a Objetos (POO) para armazenar e gerenciar alunos de uma turma.

O sistema utiliza a classe Turma para armazenar vários objetos da classe Aluno, listar os alunos cadastrados e calcular a média geral da turma.

Funcionalidades
Adicionar alunos à turma;
Listar os alunos cadastrados;
Exibir as notas e situações dos alunos;
Calcular a média da turma.
Tecnologias utilizadas
PHP 8.x
HTML
CSS
Conceitos aplicados
Programação Orientada a Objetos;
Classes e objetos;
Encapsulamento;
Tipagem forte;
Composição entre classes;
Arrays de objetos.
Como executar
php -S localhost:8000
