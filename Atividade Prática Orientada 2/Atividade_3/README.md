# Alissa Garcia Moreira

## Interfaces e Polimorfismo

Projeto desenvolvido em PHP utilizando interfaces e polimorfismo.

O sistema cria a interface `Avaliavel`, implementada pelas classes `Aluno` e `Professor`. Cada classe possui sua própria implementação do método `avaliar()`.

### Funcionalidades

* Avaliar alunos;
* Avaliar professores;
* Executar o mesmo método em objetos diferentes;
* Exibir os resultados das avaliações.

### Tecnologias utilizadas

* PHP 8.x
* HTML
* CSS

### Conceitos aplicados

* Programação Orientada a Objetos;
* Interfaces;
* Polimorfismo;
* Classes e objetos;
* Encapsulamento;
* Tipagem forte.

### Como executar

```bash
php -S localhost:8000
```

Depois, acesse:

```text
http://localhost:8000
```
