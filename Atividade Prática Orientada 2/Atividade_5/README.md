Injeção de Dependência

Projeto desenvolvido em PHP utilizando Programação Orientada a Objetos e Injeção de Dependência.

O sistema separa as responsabilidades entre a classe Aluno, responsável pelos dados acadêmicos, e a classe GeradorRelatorio, responsável pela geração do relatório.

A dependência é fornecida pelo construtor da classe GeradorRelatorio.

Funcionalidades
Armazenar dados do aluno;
Calcular a situação acadêmica;
Gerar relatório acadêmico;
Separar responsabilidades entre classes;
Utilizar Injeção de Dependência.
Tecnologias utilizadas
PHP 8.x
HTML
CSS
Conceitos aplicados
Programação Orientada a Objetos;
Classes e objetos;
Encapsulamento;
Tipagem forte;
Injeção de Dependência;
Separação de responsabilidades.
