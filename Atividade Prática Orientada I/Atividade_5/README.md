# Alissa Garcia Moreira

## Desafio Integrador

Mini sistema desenvolvido em PHP que integra cadastro de usuários, validação de dados, login, sessões e área restrita.

### Funcionalidades

* Cadastro de usuário;
* Validação dos campos;
* Login;
* Controle de acesso com sessões;
* Exibição dos dados cadastrados;
* Logout.

### Tecnologias utilizadas

* PHP
* HTML
* CSS

### Como executar

```bash
php -S localhost:8000
```

Depois, acesse:

```text
http://localhost:8000
```
