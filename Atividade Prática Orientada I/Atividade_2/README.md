Simulador de Cadastro via Formulário

Projeto desenvolvido em PHP para realizar o cadastro de usuários por meio de um formulário HTML.

O sistema utiliza o método POST, valida os campos preenchidos e exibe os dados cadastrados de forma organizada.

Tecnologias utilizadas
PHP
HTML
CSS
Como executar
php -S localhost:8000

Depois, acesse:

http://localhost:8000
