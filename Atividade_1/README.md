# Alissa Garcia Moreira

## Sistema de Classificação Acadêmica

Projeto desenvolvido em PHP para receber a nota de um aluno e informar sua situação acadêmica.

### Classificação

* Nota maior ou igual a 7: **Aprovado**
* Nota entre 5 e 6,9: **Recuperação**
* Nota menor que 5: **Reprovado**

### Tecnologias utilizadas

* PHP
* HTML
* CSS

### Como executar

```bash
php -S localhost:8000
```

Depois, acesse:

```text
http://localhost:8000
```
